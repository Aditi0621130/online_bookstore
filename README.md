# Online Bookstore Analysis & Prediction System

This project is an Online Bookstore Analysis and Prediction System developed using SQL Server and Python for data analysis, visualization, and prediction.

## Features
- Book sales analysis
- Customer and order analysis
- Data cleaning and preprocessing
- Dashboard creation using Python
- Sales trend visualization
- Predictive analysis using Machine Learning
- Business insights generation

## Technologies Used
- SQL Server
- Python
- Pandas
- Matplotlib
- Machine Learning

## Project Objective
The objective of this project is to analyze bookstore data, visualize important business metrics, and build predictive models to generate meaningful insights and future predictions.

## Files Included
- SQL Queries
- Python Files
- Dataset Files
- Visualization Outputs
